# Discovering a monotone protection law from two block counts

A reference intervention can change any subset of the free coordinates. Assume that whether a support is bad increases under inclusion, and depends only on the number of changed coordinates in each certified block. A protection succeeds exactly when the entire free complement is safe. Two masks with identical free counts have the same protection outcome.

For blocks of sizes m and n the law is an upper set on the rectangle [0,m] × [0,n]. To identify it, sweep the first coordinate upward while retaining the least bad second coordinate, initially n+1. Test the point immediately below that boundary. A positive answer lowers the boundary and a negative answer advances the sweep. At most m+n+2 membership calls occur. The resulting thresholds serve all cost vectors. For each pair of protected counts take that many cheapest coordinates per block and choose the least-cost feasible pair. This also detects a bad empty support and the absence of a feasible mask.

These bounds require the monotonicity and block permutation law to be established independently. To see the price of that assumption, remove one k-element support from the upper threshold family. The result is still monotone. Every membership query away from that support returns the same answer. Its complementary protection has size n−k and now succeeds, whereas the original threshold needs n−k+1 (1 ≤ k ≤ n). Thus a deterministic procedure certifying the ordinary threshold's optimum against unrestricted monotone alternatives from membership alone must test all size-k supports on that transcript. This lower bound concerns a different oracle from counterexample-guided search.

`BlockProtection.lean` proves complement separation, the block-count factorization, monotonicity of the puncture and transcript indistinguishability. The query bound and cost synthesis follow from the sweep and independent cheapest-coordinate choices. A reference implementation and exhaustive two-block test are in `scripts/block_frontier.py`.
